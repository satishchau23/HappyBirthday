JAGU — CINEMATIC BIRTHDAY LOVE LETTER
=====================================

This is the merged redesign: the cinematic look and animations with the birthday-focused message about what Jagu means to you. It is a static website that runs locally; it is not published online.

QUICK START
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For best results, use a browser with an internet connection so the Google Fonts can load. The site itself does not need a server.

ADD YOUR PHOTOS
Put your own image files in the photos folder and use these exact names:
- photos/photo1.jpg  (a favourite photo / first bike ride memory)
- photos/photo2.jpg  (a photo together)
- photos/photo3.jpg  (weddings, garba, Salangpur, or another favourite memory)
- photos/photo4.jpg  (Somnath or Madhavpur)

The matching photo placeholder will automatically be replaced when the file loads. Photos now use a fit-without-cropping layout, with a softly blurred background filling the frame so both portrait and landscape images look intentional. JPG is recommended; keep the exact filenames above. If you have PNG images, convert them to JPG or update the filename in index.html / script.js.

PERSONAL TOUCHES
- The sound toggle is off by default. It only plays a gentle, synthesized chime when the user turns it on; there is no autoplay music.
- The final button opens a private-feeling letter reveal with a small heart/sparkle animation.
- The page is mobile responsive and respects reduced-motion preferences.
- The text is written as a birthday love letter, not a chronological anniversary timeline.

FILES
index.html  — page structure and all text
style.css   — cinematic styling, mobile layout, and animations
script.js   — starfield, reveal effects, photo loading, sound toggle, and letter reveal
photos/     — add your own image files here

A NOTE
All relationship details and memories in the text come from the details supplied for this website. No real photos are included yet; the photo frames are placeholders until you add yours.
